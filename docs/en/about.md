# About

**Beyond the Prompt** is an independent engineering publication by a professional software architect exploring AI Engineering, tools, system design, and reproducible workflows.

**Test first. Explain second.**

Expect problem context, alternatives, trade-offs, implementation details, and explicit limitations—not hype or unverified claims.

## Author

A professional software architect exploring AI Engineering: the focus is on engineering trade-offs, reproducibility and limits. [GitHub: denis1stomin](https://github.com/denis1stomin) · [Beyond the Prompt](https://denis1stomin.github.io/beyond-the-prompt/).

The guides distinguish documentation checks from execution on a target OS. The author tested the setup approach with OpenCode v2.3.0 on macOS on November 18, 2026; Windows, Linux and Claude Code remain untested by the author.
